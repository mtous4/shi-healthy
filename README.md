# شِ هيلثي | Shi Healthy - Landing Page

صفحة هبوط تسويقية وتحويلية متكاملة لبراند الاشتراكات الصحية الأردني **شِ هيلثي (Shi Healthy)**.
مصممة بنظام **عربي أولاً (Arabic-First RTL)**، مع التركيز الكامل على تحويل الزوار إلى مشتركين وتوليد العملاء المحتملين عبر واتساب ونماذج الاشتراك.

---

## 🌟 ميزات صفحة الهبوط

1. **الهوية البصرية للعلامة التجارية:**
   - استخدام شعار شِ هيلثي المعتمد.
   - لوحة ألوان مستوحاة من هوية انستغرام: الأخضر الداكن (`#123D32`)، الأخضر الفريش (`#548E3E`)، ولمسات الليموني الحيوي (`#B7D94C`) والخلفيات الهادئة (`#F5F7EE`).
   - خطوط عربية حديثة وعالية المقروئية (`Tajawal` & `IBM Plex Sans Arabic`).

2. **مسار الاشتراك الذكي متعدد الخطوات (FLOW B):**
   - **الخطوة 1:** اختيار الاشتراك (شهري أو أسبوعي).
   - **الخطوة 2:** اختيار الوجبات مع عدادات ذكية لتقسيم الدجاج واللحمة والسمك والسلطات وحساب السعرات والبروتين.
   - **الخطوة 3:** إدخال بيانات التوصيل ومناطق عمّان مع ملاحظات التسليم.
   - **الخطوة 4:** اختيار وسيلة الدفع المعتمدة (كاش، فيزا/ماستركارد، كليك ومحافظ، أو تقسيط على دفعتين - *مستثنى منها الحوالات البنكية وApple Pay*).
   - **الخطوة 5:** تأكيد الطلب مع ملخص تفصيلي ورابط مباشر للمتابعة عبر واتساب.

3. **الأقسام التسويقية المتكاملة:**
   - **القسم الرئيسي (Hero):** صور أطباق احترافية عالية الدقة بنسبة 40-50%، عبارات واضحة ومميزات فورية.
   - **معالجة مشكلة العميل:** بلهجة أردنية عفوية ومحببة ("شو آكل اليوم؟").
   - **الرسالة الجوهرية للبراند:** *"Healthy? اه. حرمان؟ لا."*
   - **باقات الاشتراكات الشهرية والأسبوعية:** مع تفصيل الأسعار بالدينار وتوزيع الوجبات وشارة "الأكثر طلباً".
   - **تنوع الوجبات (35 وجبة دجاج + أطباق أردنية، لحوم، سمك، وسلطات):** مع فلتر تفاعلي وبطاقات ماكروز دقيقة.
   - **أهداف المشتركين:** (بناء عضل، خسارة وزن، المحافظة، حياة صحية، توفير الوقت).
   - **كيف بنشتغل؟:** 3 خطوات واضحة من الاختيار حتى الاستلام.
   - **قسم أخصائية التغذية:** طلب استشارة مخصصة عبر واتساب.
   - **التوصيل والموقع:** شفا بدران، شارع العرب، مع حاسبة مناطق عمّان والتأكيد على شفافية تكلفة التوصيل.
   - **الأسئلة الشائعة (FAQ Accordion):** تغطي جميع استفسارات العملاء بدقة.
   - **نموذج الاستشارة (Lead Form):** للزوار المترددين لمساعدتهم في اختيار الخطة.
   - **الشريط السفلي المخصص للموبايل:** زر دائم "🍱 ابدأ اشتراكك" وأيقونة واتساب سريعة.

```bash
# تشغيل خادم محلي عبر بايثون:

```
